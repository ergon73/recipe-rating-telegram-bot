# Сценарий скринкаста ATv03

Записывайте только чат с ботом. Скрыть список личных чатов и уведомления.
Не показывать .env, BotFather, терминал с конфигурацией, пользовательские базы или личные сообщения.

## Обязательный сценарий

1. Отправить `/start`: показать ответ улучшенного бота.
2. Отправить `chicken`: увидеть список и переход на следующую страницу.
3. Открыть рецепт: ингредиенты, полная инструкция, кнопки 1–5 и видео (если есть).
4. Поставить 2 ⭐ первому рецепту, затем 5 ⭐ другому.
5. Открыть избранное: показать, что 5-звёздочный рецепт выше 2-звёздочного.
6. Открыть сохранённый рецепт, поменять его оценку и показать новую сортировку.
7. Нажать видеоссылку и показать, что она ведёт к рецепту.
8. Показать удаление с отменой, затем подтверждённое удаление.
9. Через «Новый поиск» выполнить новый запрос — без повторного /start.

## Дополнительные проверки

- `zzzznotarecipe` → корректное сообщение о пустом результате.
- `курица` → объяснение английского поиска.
- Рецепт без видео → честное сообщение, без пустой видеокнопки.
- Перезапустить процесс и открыть `/favorites`: данные сохранены.
- Старый поиск после перезапуска → предложение повторить поиск.
- Сбой API проверяется автоматическими тестами; не выдавать mock-ответ за живой API.

Внешний API меняется: названия и наличие видео выбирайте по текущему ответу.
Скринкаст демонстрирует фактическое поведение, а не тестовые моки.

## Для поля сдачи

Указать, что это улучшенная версия собственной ранее выполненной работы.
Приложить свежий скринкаст и ссылку на репозиторий.
Скринкаст обязателен по рубрике; README и тесты его не заменяют.
