# Безопасность

Поддерживается ветка `main` (версия 2.x). Это учебный локальный проект, не промышленная служба.

## Сообщить о проблеме

Не публикуйте токены, Telegram ID, базу данных и журналы в публичном issue.
Для проблемы без чувствительных данных можно создать issue с обезличенными шагами.
Если проблема требует секрета или личных данных, сначала запросите у владельца приватный
канал связи; не прикладывайте их до согласования.

## Секреты и данные

- Токен хранится вне Git: локальный `.env` или переменная окружения.
- Если токен опубликован, сначала отзовите его через официальный BotFather.
  Удаление файла из последнего коммита не удаляет секрет из истории.
- `data/`, базы, `.env`, логи и виртуальные окружения запрещены в публикации.
- SQLite — не шифрование. Безопасность файла зависит от прав на машину и резервных копий.
- Поиск передаётся TheMealDB. Telegram получает сообщения и загружает фото.
- Бот не должен запускаться от администратора. Для демо ограничьте `ALLOWED_USER_IDS`.
- Сторонние ссылки доступны только по HTTPS; видеоссылки ограничены доменами YouTube.
- Секреты и текст запросов не нужны для CI. В workflow нет Telegram-токена.

Проверка `tools/check_public_tree.py` — дополнительный барьер, а не гарантия отсутствия
всех возможных секретов. Перед каждым push просматривайте staged diff.

## Зависимости

Lock-файлы содержат точные версии и SHA-256. GitHub Actions закреплены по commit SHA.
`pip-audit` проверяет известные уязвимости на момент запуска, а не доказывает абсолютную безопасность.
