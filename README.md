# 🍽 Recipe Rating Telegram Bot

[![CI](https://github.com/ergon73/recipe-rating-telegram-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/ergon73/recipe-rating-telegram-bot/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Учебный Telegram-бот: поиск рецептов, личное избранное, рейтинг 1–5 ⭐ и видеорецепты.
Развитие авторского проекта VCa03 (2025) для повторного практического задания ATv03.

> Проект для локальной учебной демонстрации. Не является круглосуточным сервисом.
> Рецепты предоставляет TheMealDB; русский интерфейс не означает автоматический перевод.

## Возможности

- Поиск по английскому названию: `chicken`, `pasta`, `Arrabiata`.
- Полная инструкция и ингредиенты без обрезания; фото при наличии.
- Оценка кнопками одновременно сохраняет рецепт в личном избранном.
- Повторная оценка заменяет предыдущую, а не создаёт дубликат.
- Сортировка по убыванию рейтинга, пагинация по 5 записей.
- Удаление с подтверждением и работающая отмена.
- Видео и ссылка на первоисточник при наличии.
- Избранные рецепты доступны из локальной базы даже при сбое API.
- Устаревшие кнопки обрабатываются понятным сообщением.
- `/help`, `/privacy`, `/cancel`; меню и поиск доступны без перезапуска диалога.

## Быстрый старт

Нужны Python 3.11–3.13, Telegram и собственный токен от официального @BotFather.
Не публикуйте токен. Остановите прежний процесс того же бота: одновременно работает один polling.

```powershell
git clone https://github.com/ergon73/recipe-rating-telegram-bot.git
cd recipe-rating-telegram-bot
py -3.12 -m venv .venv
$env:PYTHONUTF8 = "1"
.venv\Scripts\python.exe -m pip install --require-hashes -r requirements-dev.lock
.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
Copy-Item .env.example .env
# Откройте .env локально и задайте BOT_TOKEN.
.venv\Scripts\python.exe -m recipe_bot.app
```

Linux/macOS: `python3 -m venv .venv`, затем используйте `.venv/bin/python` и `cp`.
Остановить: **Ctrl+C**. Пока процесс не работает, бот не отвечает.

Для чтения уже существующего секрета без копирования:
`python -m recipe_bot.app --env-file /path/to/private/.env`.
Переменные окружения процесса имеют приоритет. Относительный `DATABASE_PATH` считается
от корня проекта. Никакой автоматической миграции старого `favorites.json` нет:
старый проект и его данные остаются нетронутыми.

## Проверка качества

```powershell
.venv\Scripts\python.exe -m pytest --cov=recipe_bot --cov-report=term-missing
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
.venv\Scripts\python.exe -m pip_audit -r requirements-dev.lock --disable-pip --no-deps
```

Тесты используют временную SQLite и поддельный HTTP-транспорт. Реальный Telegram-токен
и интернет для unit-тестов не нужны. Для CI и повторяемой установки используются lock-файлы.
Ручная демонстрация описана в [docs/DEMO.md](docs/DEMO.md).

## Архитектура

```text
src/recipe_bot/
  app.py       — обработчики Telegram, конфигурация и запуск
  api.py       — асинхронные HTTP-запросы, тайм-ауты, ограниченный повтор
  models.py    — валидация рецептов и внешних ссылок
  storage.py   — SQLite, атомарные записи, изоляция пользователей
  views.py     — клавиатуры, пагинация, разбиение длинных инструкций
tests/         — регрессионные и модульные тесты
docs/          — сценарий демонстрации и журнал улучшений
```

Не используется ConversationHandler: текстовый поиск доступен из любого состояния.
Результаты текущего поиска держатся в памяти; кнопки содержат ID сессии.
Сохранённый рецепт — локальный снимок данных на момент оценки, не автоматически обновляемая копия.
При одинаковом рейтинге порядок стабилен: название, затем ID.
Все сообщения с внешним текстом отправляются без HTML/Markdown-разметки.

## Приватность и безопасность

- Реальный секрет — только в локальном `.env` или окружении процесса.
- `.env`, базы SQLite, журналы, избранное и окружение исключены из Git.
- Бот работает только в личных чатах. `ALLOWED_USER_IDS` ограничивает участников демо.
- В базе хранятся Telegram ID, оценка и снимок рецепта. Имя, телефон и переписка не сохраняются.
- Запрос блюда передаётся TheMealDB; фото и сообщения обрабатывает Telegram.
- Видео и первоисточник открываются на внешних сайтах по нажатию пользователя.
- В логах нет текста запросов и ответов API; фильтр скрывает токены в сообщениях библиотек.
- Один процесс на токен. Активный webhook не отключается автоматически.
- Утёкший токен отзовите в BotFather, замените локально и проверьте историю Git.
- Не храните базу в публичной облачной папке. Ограничьте доступ к машине и резервным копиям.
- [Политика безопасности](SECURITY.md), [правила участия](CONTRIBUTING.md).

## Ограничения

TheMealDB в основном содержит английские названия и инструкции. Русские запросы не переводятся:
бот объясняет ограничение. Отсутствие видео — допустимое состояние, а не ошибка.

Используется бесплатный тестовый ключ `1` для обучения. Публичный GitHub-репозиторий
не равен публичному промышленному сервису. Для промышленного выпуска изучите текущие
[условия TheMealDB](https://www.themealdb.com/docs_api_guide.php) и production-ключ.
Платные интеграции не используются.

До 500 избранных рецептов на пользователя. Обновления обрабатываются последовательно;
это сознательное ограничение учебного однопроцессного запуска, а не высоконагруженная архитектура.
Не проверяет пищевые аллергии и не выдаёт медицинских рекомендаций.
